# neoclient1.0.1

neoclient1.0.1 is a Minecraft Java Edition Forge 1.8.9 client-side mod designed for TLauncher. It features a custom GUI menu that opens when you press the RIGHT SHIFT key. The menu has a dark theme with a modern, clean interface, smooth animations, and stylish buttons. The menu is centered on the screen and includes multiple clickable buttons.

## Install

1. Download the mod file.
2. Place the mod file in the `mods` folder of your TLauncher Minecraft instance.
3. Launch Minecraft using TLauncher.

## Use

1. Launch Minecraft using TLauncher.
2. Press the RIGHT SHIFT key to open the custom GUI menu.
3. Click on the buttons in the menu to perform actions.
